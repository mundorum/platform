# platform
Reference platform to edit and play compositions.

| Path | What |
|------|------|
| `server/` | Shared Django server: portal (`/`), sign-in, LLM gateway |
| `noid/` | noid: compose and run n-o-id scenes (`/noid/`) |
| `vp/` | VP Studio: virtual patient activities with LLM agents (`/vp/`) |
| `gno/` | gno narrative editor (standalone) |

Documentation: <https://mundorum.github.io/platform/> (sources in `docs/`,
`noid/docs/`, `vp/docs/`).
